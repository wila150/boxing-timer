# 企劃：RoundBell 拳擊計時器（獨立 Web App）

任何人都能用的拳擊／HIIT 回合計時器 Web App（PWA）。2026-11-16 從突破重圍網站 `/timer` 獨立出來（突破重圍那份保留不動）。可「加入主畫面」當 App 用、斷網也能開。

## 做法（網頁版對應原規格）

| 原規格 | 網頁版做法 |
|---|---|
| MVVM 分層 | `public/index.html` 內分三塊：Engine（時間戳記＋狀態機，不碰畫面）→ Store（localStorage）→ View（只讀 Engine 狀態畫畫面） |
| 高精度計時 | 記「這一段的結束時間戳」，每幀 `結束 − performance.now()`；暫停時記剩餘毫秒 |
| 背景執行 | 每段開始時把該段所有鐘聲用 Web Audio `start(when)` 預排；回前景用時間戳快轉補狀態（不補放錯過的聲音） |
| 音訊混音 | iOS Safari `navigator.audioSession.type = 'transient'`（壓低音樂不打斷）；不支援就照常播放 |
| 預載音效 | 鐘聲／木魚／嗶聲都用 Web Audio 即時合成，零下載零延遲 |
| 震動 | `navigator.vibrate`（Android 有，iPhone 網頁不支援） |
| 防休眠 | Screen Wake Lock，訓練中開、待機/完成放掉 |
| 課表／紀錄 | localStorage `roundbell_v1`（只存在這支手機） |

## 狀態機

Idle →（開始）Prepare 黃 → Round 綠 →（剩警告秒數）Warning 橘閃 → Rest 紅 → 下一回合 … 最後一回合結束 → Finished
- 最後一回合沒有休息；準備 0 秒就直接進回合
- 點畫面任意處＝暫停／繼續；長按 0.8 秒＝結束
- 音效：回合開始 1 響鐘、回合結束 3 響鐘、警告木魚、半回合嗶（可關）、準備/休息最後 3 秒嗶、完成長鐘；語音報時（中文）可選

## 預設課表
職業拳擊 3:00/1:00×12、業餘拳擊 2:00/1:00×3、HIIT 0:40/0:20×8、Tabata 0:20/0:10×8；可新增/改/刪自訂課表

## v1.1 擴充（2026-11-16 使用者規格：Web 解方＋SEO 路由＋資料結構＋技術棧）

### Web 先天限制解方
- 防休眠：Wake Lock（已做）
- 背景不掉秒：計時 tick 移進 Web Worker，仍用「結束時間戳 − 現在」計算（已用時間戳）
- 音效：合成音在按「開始」那一下用 OfflineAudioContext 預先算成 AudioBuffer 存成音效池，之後直接播
- 語音喊招：SpeechSynthesis 在回合中依課表念招式（例：「刺拳直拳」「最後十秒」）
- PWA 離線：已做；改架構後要確保所有課表頁都進快取

### 路由（靜態生成，給 Google 收錄）
1. `/` 快速計時器：一打開就是 3:00／1:00 經典拳擊，零註冊
2. `/routines` 課表總覽：依目標分類卡片（熱身與手腕保護、空擊步法節奏、重沙袋爆發力、拳擊核心 HIIT、訓練後肩頸伸展）
3. `/routines/[slug]` 課表頁（SEO 關鍵頁）：上半計時器、下半完整動作步驟＋時間軸
4. `/builder` 自訂課表：從動作庫勾招式、設秒數 → 整份課表壓進網址（Base64），免登入永久分享連結

### 資料
- 靜態層：`src/data/moves.json`（官方動作庫）、`src/data/routines/*.json`（精選課表），打包進網站
- 本機層：localStorage（自訂課表、鐘聲偏好、歷史回合）
- 引擎要從「固定回合×N」改成「段落清單」：課表＝多段 `{名稱, 類型 work/rest/prepare, 秒數, 喊招清單}`，經典拳擊只是其中一種

### 技術棧（2026-11-16 使用者確認）
- Astro＋Tailwind 純靜態，部署 GitHub Pages（跟萬劍仙途一樣 push 就更新；repo 公開），網址 `wila150.github.io/boxing-timer/`
- 不用 Firebase；品牌名暫用 RoundBell

## v1.2 統整架構（2026-11-16 使用者企劃檔 `OneDrive\Desktop\網站架設企劃\拳擊app 企劃.txt`）

跟現況比，要新增／改的（其餘已做）：
| 項目 | 規則 |
|---|---|
| 頂部進度條 | 改成畫面最上方 5px，GPU 縮放（transform）；待機隱藏、休息時紅色 |
| 最後警告 | 橘色＋**全螢幕邊框呼吸光暈**（取代整片閃）；進入警告就停止喊拳 |
| 教練喊拳 | 拳法庫分「基礎」（1～6 號數字拳組合）／「進階」（加閃躲、潛避、格擋、步伐）；節奏 慢／中／快 隨機抽題；回合開始延遲避開鐘聲；每次念之前清空語音佇列；主畫面同步顯示字幕 |
| 休息副標 | 休息時副標題顯示技術提醒（輪播） |
| 訓練中 | 底部課表列、右上設定圖示**淡出**；暫停／結束時 Wake Lock 釋放、繼續時再鎖 |
| 分享課表 | 名稱、回合／休息秒數、回合數、警告、音效、喊拳設定編進網址參數；設定頁底部「一鍵複製分享連結」 |
| 收到分享 | 開啟時解析＋驗證數值範圍 → 彈窗顯示摘要：「單次使用」或「儲存並套用」；之後 `history.replaceState` 清掉網址參數 |
| 設定頁 | 新增「教練喊拳」區塊：開關、基礎／進階、節奏 |

畫面由上到下：5px 進度條 → 課表標題 → 喊拳字幕 → 超大倒數 → ROUND 進度。
